
# CTI Reports Analysis (English) 🛡️🔍

Welcome to my **Cyber Threat Intelligence (CTI) Analysis** repository. This project is dedicated to dissecting and analyzing technical reports from top cybersecurity firms (CrowdStrike, Mandiant, Palo Alto, etc.) to extract actionable intelligence and improve defense mechanisms.

## 🎯 Objective
The goal is to move beyond just reading reports. I break down complex vendor reports into:
- **Core Attack Vectors:** How the breach started.
- **Vulnerability Mapping:** Linking incidents to specific CVEs.
- **TTPs:** Mapping actor behavior to the MITRE ATT&CK framework.
- **Actionable Advice:** Practical steps for security teams.
